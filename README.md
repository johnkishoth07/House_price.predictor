# 🏡 House Price Predictor

An end-to-end **Machine Learning** application that predicts residential house prices based on property features such as area, bedrooms, bathrooms, parking, furnishing status, and other housing characteristics. The project demonstrates the complete machine learning workflow, from data preprocessing and model training to deployment using Streamlit.

---

## 📌 Project Overview

The House Price Predictor is designed to estimate the market value of residential properties using historical housing data. Users can enter property details through an interactive Streamlit web interface and receive an instant price prediction generated by a trained machine learning model.

This project showcases practical skills in data preprocessing, feature engineering, regression modeling, model evaluation, and deployment.

---

## 🚀 Features

* Predicts house prices in real time.
* Interactive and user-friendly Streamlit interface.
* Data preprocessing and feature engineering pipeline.
* Machine learning model trained using XGBoost Regressor.
* Fast predictions using a serialized Joblib model.
* Clean and modular project structure.

---

## 🛠️ Tech Stack

* **Programming Language:** Python

## 📂 Dataset

The model was trained using a structured housing dataset containing multiple property attributes, including:

* Area
* Number of Bedrooms
* Number of Bathrooms
* Number of Stories
* Parking Spaces
* Main Road Access
* Guest Room Availability
* Basement
* Hot Water Heating
* Air Conditioning
* Preferred Area
* Furnishing Status

These features were used to predict the target variable: **House Price**.

---

## 🧹 Data Preprocessing

Before training the model, the dataset underwent several preprocessing steps:

* Checked for missing values.
* Removed duplicate records.
* Verified and corrected data types.
* Encoded categorical variables using Label Encoding.
* Selected relevant features for prediction.
* Split the dataset into training and testing sets.
* Prepared numerical input suitable for machine learning algorithms.

---

## 🤖 Machine Learning Model

This project uses **XGBoost Regressor (XGBRegressor)**, a gradient boosting algorithm that builds multiple decision trees sequentially. Each tree learns from the errors of the previous trees, resulting in improved prediction accuracy and strong performance on structured tabular datasets.

---

## 📈 Model Workflow

1. Load the housing dataset.
2. Clean and preprocess the data.
3. Encode categorical variables.
4. Split the dataset into training and testing sets.
5. Train the XGBoost Regressor model.
6. Evaluate the model using regression metrics.
7. Save the trained model using Joblib.
8. Deploy the model with Streamlit for real-time predictions.

## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/House_Price_Predictor.git
```

Navigate to the project directory:

```bash
cd House_Price_Predictor
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
